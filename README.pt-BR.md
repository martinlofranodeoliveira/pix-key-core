# pix-key-core

Classificação e validação de chaves PIX: CPF, CNPJ, e-mail, telefone,
EVP. Zero dependências, Node >= 22.

Parte do laboratório open source da LOFRANO TECNOLOGIA. MIT.

```sh
npm test          # 2 testes, 12 asserções, node:test, sem dependências
npm run demo
```

Somente sintaxe. MIT — veja `LICENSE`.
